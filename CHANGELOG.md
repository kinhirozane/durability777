# Changelog

## [Unreleased]

### Added

- Added configurable durability warning colors, disabled by default.
- Added support for the Percentage unit system.
- Added Japanese localization.

### Changed

- Changed the colors of unit system toggle messages to improve readability.
- Changed the unit system key mapping's translation keys and text to better describe its cycling behavior.

- Fixed unit system toggle messages displaying the previous unit system name instead of the new one.

## [1.0.0] - 2026-11-16

### Added

- Added durability value display above vanilla durability bars.
- Added support for multiple durability unit systems.
