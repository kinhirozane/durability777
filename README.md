## Features

- Displays the current durability value above each item's vanilla durability bar.
- Supports multiple durability unit systems.

## Durability Unit Systems

Choose from different unit systems to display durability values in your preferred format.

- Chinese Myriad — Uses the Chinese myriad-based numbering system.
- Metric (SI) Prefix — Uses standard metric prefixes.
- Short Scale — Uses the short-scale numbering system.

# Installation

Durability777 is a client-side mod. It only needs to be installed on the client and does not need to be installed on the server.

## Usage

Press the configured key combination to cycle through the available durability unit systems.

That's it. Simple and intuitive.
